Introduction to Tailwind CSS

Tailwind CSS is a Utility-First CSS Framework used to build modern and responsive websites quickly.

Why use Tailwind?

  • Style elements quickly
  • features :
    • Filters
    • Dark mode
    • CSS variables
    • P3 colors
    • CSS grid layout
    • Transitions and animations
    • Cascade layers
    • Container queries
    • Logical properties
    • 3D transforms
  • Gradients -
  • Create responsive designs "Mobile first"
  • Develop websites faster
  • Reuse utility classes
  • Control spacing, colors, fonts, borders, etc.
  • Build modern UI without writing a lot of custom CSS

This means:

  • text-sm → small text on mobile
  • md:text-lg → larger text on medium screens
  • lg:text-2xl → even larger text on large screens

Tailwind CSS depends heavily on composing (combining) utility classes rather than creating one custom class for every component.
